# Implementation Log: Task 12

**Summary:** Task 12: the RDF writer now writes N-Triples into an `.nt` body (Requirement 5.5, finding B7). This is a defect fixed on purpose. Before, a triple added to a subject that already had a statement was written as a Turtle `;` continuation, and `rdf:type` was written as `a`.

What changed:
- **N-Triples body:** each added triple is a full statement line below the subject's last one, with every predicate written as its IRI.
- **Turtle body:** written as before.
- **Where the syntax comes from:** `RdfEditHandler` reads it from the command's `BodyPath`, because the edit copy is parsed from text and never learns its path. It passes the syntax through a new virtual `Apply` overload, which `AddRdfTripleCommand` overrides.
- **Guard:** `RdfWriterNTriples.Tests`. Its two `.nt` tests were seen to fail against the old writer, on `;` and on `a`; the red run is in `rdf-t12-red.log`.
- **Transcripts:** regenerated once.
  - Every changed hunk is an add-triple edit on `simple.nt` or `marie-curie.nt`.
  - Two later rename hunks in the same documents changed only their line numbers.

Deviations and remaining work:

- **Fixture:** `Fixtures/simple.nt` is unchanged.
