# Implementation Log: Task 2

**Summary:** The loader now builds the grammar of a body of the grammar family (standalone PR #782, merge `2557ffb`; tasks taken from etalii.adp `4696ce0`). `EtAlii.Lark` 0.4.0 is a central package with its MIT licence named in `Directory.Packages.props` and listed in `docs/dependencies.md`. `BindingReader` reads `family: grammar`, `body.grammar` as text or `{"file"}`, `body.start` and `body.recover`. `FblDocumentLoader.Load(byte[] json, string? folder)` passes the document's folder. `Files/Grammar/GrammarNotation.cs` ports `atd-grammar.py`'s `lint_text` and `regex_problems`. `Files/Grammar/GrammarBuild.cs` reads a file and its `%import .x` only from beside the document, then applies the 256 KiB bound and the lint. It refuses a `recover.unit` that is no rule before the build, since Lark refuses an unknown start symbol on its own. It builds strict LALR(1) with the contextual lexer, ECMAScript regular expressions, `MaybePlaceholders` and `PropagatePositions`, applies the 4,096-rule and 32,768-state bounds, and checks `recover`: its unit is a rule, the start rule is `unit*`, and each `sync` entry is a terminal or the text of an anonymous string terminal. Every refusal is a problem at the body's pointer, and a grammar that loads keeps its build on the binding. `GrammarLoading.Tests` has the vendored Turtle grammar building and one load-then-plant test for each refusal of the task, pointer and words asserted. Every refusal test and the state-bound test were seen to fail under sabotage, and so was the assertion that a loaded grammar is built. The conformance guard became `TheGrammarFixturesAreRefusedForTheirSlots`: the three pending fixtures now fail on their slots ("A slot names exactly one place (FBL §3.3).") rather than on their family, until T003 admits `{node}`. Measured with 0.4.0: 4,096 chained rules made the build take more than ten minutes, so the rule-bound test uses 13 optional keywords, which expand to 8,196 rules in under a second. The four gates exited zero (18,229 tests, 0 failed), and inspect.sh is clean once the build's internals are private.
