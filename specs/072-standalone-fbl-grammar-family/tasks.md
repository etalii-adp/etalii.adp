One Developer owns this specification and works its tasks in order. **Every task is one pull request into standalone's `develop`**, from its own worktree `.claude/worktrees/072-<task>/` on `features/072-<task>`, whose four gates and `inspect.sh` exit zero in a fresh worktree before it is pushed, judged by captured exit codes. Each pull request's description names `specs/072-standalone-fbl-grammar-family/` in etalii.adp and the etalii.adp commit these tasks were taken from. Each task starts after the one before it has merged, because each builds on the last: the corpus, the loader, the tree, the partial reading, the writing, the split slot, the close.

The specification uses requirements rather than user stories, so a task's label names the requirements it claims (`[R2]`); file paths carry their repository, `etalii.adp.ide.standalone/`, as everywhere in etalii.adp.

## Implementation strategy

The minimum that is worth merging on its own is T001 to T004: the library reads a Turtle body through its grammar. T005 and T006 complete FBL 0.9 and the two fixtures that hold a host to it; T007 is the amendment; T008 is the record. Each pull request leaves `develop` green and changes no module's behaviour, so the work can stop after any task without leaving anything half-built.
