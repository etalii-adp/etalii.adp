# Designer definitions

This folder is a placeholder. It will hold the files for ADP's designer types, the form-based visual layouts in which nothing is connected:

- **DESL specification files** (`.desl`), in which a tool engineer specifies one designer type ([DESL](../../specifications/desl/DESL-specification.md));
- **DED definition files** (`.ded`), each one designer a user created of such a type ([DED](../../specifications/ded/DED-specification.md)).

No designer exists yet, and DESL and DED are placeholders too. The words used here are defined in [docs/terminology.md](../../docs/terminology.md).
